# Portfólio · Maiara Machado · Design Educacional

Abra `index.html` no navegador. Cada peça fica na própria pasta e também abre sozinha.

| Pasta | Peça | Formato |
|---|---|---|
| `design-thinking/` | Design Thinking: Módulo 1 + apostila em PDF | Curso autoinstrucional |
| `metas/` | Metas que Movem Resultados | Minicurso |
| `phishing/` | Esse e-mail é confiável? | Objeto interativo (simulador) |
| `dns/` | Do endereço à página | Objeto explicativo |

As peças `design-thinking`, `phishing` e `dns` compartilham a mesma base visual e a mesma organização de código: dados separados da lógica, scripts clássicos (abrem direto do arquivo, sem servidor) e um README em cada pasta.
